# Changelog — NeuFin Decision Assurance Envelope

## v1.0.0 — 2026-09-19

Initial public release of the specification.

- `schema/v1.schema.json` — JSON Schema (draft 2020-12) for the envelope.
- Four worked examples covering each disposition: `PROCEED`, `REVIEW`,
  `ESCALATE`, `DENY`.
- `docs/field-reference.md` — full field-by-field reference.
- `docs/integration.md` — producing, validating, and consuming envelopes.
- Minimal, dependency-free TypeScript and Python validator examples.
